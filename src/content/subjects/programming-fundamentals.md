faqs:
  - question: Which programming language do these notes use for examples?
    answer: >
      Examples are written in C-style pseudocode and C, because most board
      and university exams use C-family syntax. The concepts (variables,
      loops, functions, arrays) transfer directly to languages like Python,
      Java, and JavaScript.
  - question: What is the difference between a syntax error and a logic error?
    answer: >
      A syntax error breaks the rules of the language, so the program does
      not compile or run at all. A logic error compiles and runs but produces
      the wrong result, like using < when you meant <=. Our control
      structures note shows worked examples of both.
  - question: How do I memorize all the operators and precedence rules?
    answer: >
      Do not memorize precedence tables. Use parentheses to make intent
      explicit, and learn the four groups that matter most: arithmetic,
      comparison, logical, and assignment. The practice questions in this
      subject drill these until precedence becomes intuition.
  - question: Are the practice questions enough for board exam preparation?
    answer: >
      They cover the recurring question patterns, but pair them with past
      papers from your own board. Our questions include full explanations of
      why each answer is right, which past papers usually do not.
